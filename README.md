# Dog Viewer

A small React application for browsing random dog images and managing a favorites list.

The application was created as a timeboxed frontend coding assignment.


For architecture decisions, scalability notes, and future improvements, see the  [Documentation](./src/doc/documentation.md)

## Tech stack

- React
- TypeScript
- Vite
- SCSS
- Vitest
- React Testing Library

## Running locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```
Run linting:

```bash
npm run lint
```
Run tests:

```bash
npm run test:run
```
